# 📈 Stock Price Predictor with Linear Regression

This project predicts future stock prices for a company (default: Apple Inc. - AAPL) using historical data fetched from the Alpha Vantage API. The model uses **Linear Regression** from `scikit-learn` to forecast stock prices 50 days ahead.

---

## 🚀 Features

- Fetches historical stock data using **Alpha Vantage**
- Uses **Linear Regression** for price forecasting
- Scales and preprocesses data using `sklearn`
- Visualizes both actual and predicted prices using `matplotlib`
